💰 Telegram WalletBot

Веб-приложение кошелька с интеграцией Telegram бота и базой данных SQLite.

🚀 Возможности

- ✅ Регистрация пользователей через Telegram
- ✅ Пополнение и вывод средств
- ✅ История всех транзакций
- ✅ Веб-интерфейс для управления кошельком
- ✅ Админ-панель для управления пользователями
- ✅ Настройка лимитов на операции
- ✅ Система банов пользователей
- ✅ Полная история транзакций в базе данных

📋 Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Получите токен бота у @BotFather

3. Откройте `main.py` и замените `YOUR_BOT_TOKEN_HERE` на ваш токен:
BOT_TOKEN = 'ваш_токен_здесь'

4. Запустите приложение:
python main.py

🔑 Использование

 Для пользователей:

1. Откройте бота в Telegram и отправьте `/start`
2. Получите код для входа
3. Войдите на веб-сайт используя код
4. Управляйте своим балансом через веб-интерфейс

Команды бота:

- `/start` - Регистрация/вход и получение кода
- `/balance` - Проверка баланса
- `/history` - История последних транзакций

Админ-панель:

- Код для входа: `ADMIN123`
- Управление пользователями
- Выдача баланса
- Бан/разбан пользователей
- Настройка лимитов

🗄️ База данных

База данных SQLite автоматически создается при первом запуске и содержит:

- users - Пользователи (TG ID, баланс, статус)
- transactions - Все транзакции (пополнения, выводы)
- login_codes - Коды для входа на сайт
- settings - Настройки лимитов

⚙️ Настройки

По умолчанию:
- Мин. пополнение: 10 ₽
- Макс. пополнение: 100,000 ₽
- Мин. вывод: 50 ₽
- Макс. вывод: 50,000 ₽

Настройки можно изменить в админ-панели.
